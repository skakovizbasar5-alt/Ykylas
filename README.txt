ЫҚЫЛАС ДҮКЕНҰЛЫ — сайт (өз хостингке арналған нұсқа)
=====================================================
Бұл нұсқада YouTube видеосы сайттың ішінде ойнайды.

GitHub Pages-ке салу (тегін):
 1. github.com сайтында тіркеліңіз (немесе кіріңіз).
 2. Оң жақ жоғарыдағы «+» → «New repository». Атауын жазыңыз (мысалы: ikylas),
    «Public» таңдаңыз → «Create repository».
 3. Ашылған беттен «uploading an existing file» сілтемесін басыңыз.
 4. ikylas-site папкасының ІШІНДЕГІ барлық нәрсені (index.html, assets папкасы,
    .nojekyll) браузер терезесіне сүйреп апарыңыз → төменде «Commit changes».
    (Бір реттегі шек — 100 файл, әр файл 25 МБ-тан аз: бұл жобаға жетеді.)
 5. Settings → Pages → «Branch: main», папка «/ (root)» → Save.
 6. 1–2 минуттан кейін сайт мына адресте ашылады:
    https://ПАЙДАЛАНУШЫ-АТЫҢЫЗ.github.io/ikylas/

Компьютерде тексеру: папканың ішінде  python -m http.server 8000  →  http://localhost:8000
